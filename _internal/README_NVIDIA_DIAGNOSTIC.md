# NVIDIA: проверка совместимости

## Что исправлено

- Автовключение ожидает доступный оверлей и наблюдаемое состояние в течение 60 секунд после запуска игры. Не нажимает переключатель при неизвестном состоянии; уже включённый повтор не выключается
- Запросы сериализованы: два одновременных «включи» не дают двойного переключения
- Ручные изменения наблюдаемого состояния сообщаются один раз; краткая потеря доступа не уничтожает предыдущее наблюдение
- Открытие Alt+Z больше не останавливает проверку при живом игровом процессе
- Очищенные сочетания клавиш остаются выключенными; недопустимые команды не отправляют клавиши
- Неизвестное состояние записи не подменяется локальным предположением. Запуск/остановка не нажимает Alt+F9 вслепую
- Если новый стабильный видеофайл не найден, результат не объявляется успешным сохранением

## Важное ограничение NVIDIA App

Наличие процесса NVIDIA App не означает работающий оверлей. Сохранённый ShareSettings и оставшийся после миграции DVREnabled не доказывают фактическую работу повтора.

Для NVIDIA App NEO принимает только доступное живое состояние ToggleState конкретного элемента «Мгновенный повтор» / «Запись» в открытом, активном, принадлежащем NVIDIA оверлее. UI Automation доступен не во всех версиях оверлея. Скрытый оверлей, недоступный элемент или неоднозначное состояние дают `null`, а не «выключен». NEO не открывает оверлей сам и не захватывает экран.

Пока конкретная версия NVIDIA App не проверена на Windows, фоновое автовключение и уведомления при закрытом оверлее не считаются подтверждёнными. Если установленная версия не предоставляет живое состояние, эта сборка честно откажется от опасного переключения. Тесты на подставных адаптерах не заменяют проверку на видеокарте.

## Минимальная диагностика на компьютере с NVIDIA

1. Запишите версию NVIDIA App из её настроек. Проверьте, что в NEO включены «Игры», желаемое автовключение и уведомления об изменениях
2. В папке NEO откройте терминал и выполните `NEO.cmd --nvidia-diagnostic`. Через пять секунд он прочитает только состояние. Первый запуск оставьте с закрытым оверлеем
3. Повторите команду и в течение пяти секунд откройте Alt+Z вручную. Сравните показанное в оверлее состояние с полями `instant_replay` и `recording`
4. Если хотите проверить распознавание обоих состояний, самостоятельно измените мгновенный повтор в оверлее и повторите шаг 3. Включение повтора запускает буфер записи NVIDIA; выполняйте это только для разрешённого к записи содержимого
5. Пришлите два коротких JSON-результата и номер версии. Не нужны ShareSettings целиком, реестр целиком, снимки рабочего стола или учётные данные

Диагностика не устанавливает программы, не меняет настройки, не открывает оверлей, не нажимает клавиши, не записывает экран/микрофон. Если уже установленного Python NEO нет или он неисправен, выводится недоступность без автоматической установки.

Основной публичный `NEO.exe` является GUI-загрузчиком: команда `NEO.exe -m ...` для диагностики не поддерживается.

## Реализованные функции

NVIDIA: сохранить клип; начать/остановить запись при наблюдаемом состоянии; включить/выключить/явно переключить мгновенный повтор; проверить его состояние; игровые уведомления и автозапуск при включённой настройке.

Обычные команды скриншота используют Windows, а не NVIDIA. Отдельных команд NVIDIA для открытия оверлея, микрофона, фильтров, Photo Mode или Highlights в этой версии нет.

## Источники API

- NVIDIA: [обзор оверлея и настраиваемых клавиш](https://www.nvidia.com/en-us/geforce/news/nvidia-app-download-and-features/)
- Microsoft: [состояние TogglePattern](https://learn.microsoft.com/en-us/dotnet/api/system.windows.automation.togglepattern.togglestateproperty)
- pywinauto: [get_toggle_state: 0, 1, 2](https://pywinauto.readthedocs.io/en/latest/code/pywinauto.controls.uia_controls.html)

Документация Microsoft/pywinauto определяет интерфейс наблюдения; она не гарантирует, что конкретная версия NVIDIA реализует его.

## Проверено в этой среде

Подставные адаптеры проверяют запуск NVIDIA App, отсутствие поддержки прежних процессов и путей, неизвестное/исчезнувшее состояние, отсутствие чтения прежнего реестра, сохранение пользовательских настроек, уведомления и безопасный маршрут диагностики. Фактические итоги запусков и хеш проверенного кода хранятся в отдельных отчётах QA.

Реальная Windows, NVIDIA App, видеокарта, горячие клавиши в For Honor, доступность UI Automation в установленной версии и качество видео/звука здесь не проверялись. Новая диагностика предназначена для закрытия именно этой неопределённости.


## Запуск установленного приложения при старте игры

В «Настройки → Игры → Мгновенный повтор NVIDIA» добавлены три независимые настройки:

- Уведомления NVIDIA в чате: общий переключатель пассивных сообщений. Ответы на явные команды остаются информативными
- Сообщения об отсутствующем оверлее и результате запуска приложения: отдельный тип уведомлений
- Запуск установленной NVIDIA App при старте игры: выключен по умолчанию

Для запуска приложения с последующим включением повтора включите также существующее автоматическое включение мгновенного повтора. Оно действует только при подтверждённом состоянии «выключен». Сообщение об успешном автоматическом включении следует настройке сообщений об изменениях; ошибки следуют предупреждениям о выключенном или неизвестном повторе.

NEO ищет только NVIDIA App в стандартных папках Program Files: `NVIDIA Corporation\NVIDIA App\CEF\NVIDIA app.exe`. Проверка процессов не запускает приложение повторно, если уже найдена NVIDIA App или её оверлей NVIDIA Overlay. Недоступная проверка процессов не считается отсутствием программы. Нестандартные пути установки автоматически не перебираются.

Запуск использует только документированный запрос Windows `STARTF_USESHOWWINDOW` с `SW_SHOWMINNOACTIVE`: первое окно просят показать свёрнутым без активации. Приложение NVIDIA может изменить поведение последующих окон; сохранение фокуса игры на реальной Windows здесь не подтверждено. Не используются неофициальные параметры командной строки, установка приложений/драйверов, повышение прав или изменение настройки оверлея.

60 секунд — общий срок ожидания готовности после обнаружения игры, а не интервал проверки. Используется существующая проверка игровой сессии: по умолчанию раз в 4 секунды, с существующим ограничением 3–30 секунд. Дополнительного постоянного опроса нет. На первом опросе с доступным оверлеем и подтверждённым состоянием «выключен» выполняется безопасное включение. Выход из игры, остановка наблюдателя, смена профиля и отключение соответствующих настроек отменяют ещё не выполненные действия. Уже запущенное приложение при отмене не закрывается.

Проверки с подставными адаптерами покрывают установленную/отсутствующую/уже работающую программу, ошибку запуска, неизвестную проверку процессов, ожидание готовности, истечение срока, повтор события, отмену и смену профиля, отключённые настройки, неизвестное состояние без нажатия клавиш, сохранение/отмену настроек и семь языков. Реальный запуск NVIDIA, поведение фокуса, совместимость живого состояния с установленной версией NVIDIA и фактическая запись видео не проверялись.

Документация запроса окна Windows:

- https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/ns-processthreadsapi-startupinfow
- https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindow


## Совместимость прежних настроек

Горячие клавиши, автозапуск, автовключение, уведомления и выбранная в NEO папка видео сохраняются. Удаляется только прежняя настройка имён значений реестра `gaming.instant_replay.registry_values`: она больше не используется. Постоянного переключателя между приложениями в настройках NEO нет; доступность определяется только по NVIDIA App. Если её нет, результат — «недоступно».

Папка видео берётся из явного выбора пользователя в NEO или стандартной папки Windows «Видео». У прежнего автоматического чтения `DefaultPathW` нет подтверждённого происхождения из текущей NVIDIA App, поэтому оно удалено. Это не утверждение о несовместимости самого ключа. Если в NVIDIA App выбран другой каталог, укажите его в «Настройки → Игры → Клипы и запись NVIDIA». Проверка нового стабильного файла сохранена.

Для NVIDIA App 11.0.9.251 при закрытом оверлее состояние по-прежнему неизвестно. Сохранённые настройки и наличие процесса не заменяют наблюдение. NEO не меняет DesktopCapture, не обновляет приложение или драйвер и не включает новые способы доступа.
