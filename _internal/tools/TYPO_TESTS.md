# Опечатки, неправильная раскладка и неверно услышанные слова (NEO 165–166)

NEO понимает команды с ошибками: «открйо папку», «откройпапку загрузки», «вклюи музыку», «какая пагода», «поставь ан паузу», а также текст, набранный в неправильной раскладке: «jnrhjq gfgre», «ghbdtn». Всё работает локально, без нейросети и без интернета.

## Как это устроено

1. **Раскладка.** Слово в латинице переводится с QWERTY на ЙЦУКЕН, только если после перевода оно становится известным словом. Настоящие латинские названия (Steam, Discord, Spotify, YouTube) не меняются. Для голоса этот шаг отключён.
2. **Мягкое исправление (до маршрутизации).** Незнакомое слово заменяется ближайшим командным словом. Стоимость правки зависит от вида ошибки: соседняя клавиша, двойная или пропущенная буква, переставленные буквы, безударная гласная. Исправление принимается, только если исправленный текст разбирается как команда, а исходный не разбирается. Настоящее слово («пагода») исправляется, только если вся фраза становится командой из одних командных слов («какая погода»).
3. **Последний шанс (вместо «Не совсем понял»).** Разрешены короткие слова и настоящие слова («ан» → «на»). Кандидат проверяется парсером и маршрутизатором, после этого работают обычные правила владения, риска и подтверждения. Для голоса сначала пробуются другие гипотезы Whisper той же фразы.

Никогда не меняются:

- отрицание («не вклюи музыку» остаётся без действия);
- текст в кавычках, пути, ссылки;
- формы глаголов, кроме повелительного наклонения («я включил музыку» не становится командой).

Угадывание никогда не создаёт отправку, удаление или выключение: «удлаи файл», «выклюич» не исправляются. Если две разные команды одинаково вероятны, NEO спрашивает, какую имели в виду.

## Все языки приложения (NEO 166)

Исправление работает для всех 7 языков: русского, английского, немецкого, французского, испанского, итальянского и португальского.

- Для каждого языка учитываются своя раскладка клавиатуры (ЙЦУКЕН, QWERTY, QWERTZ, AZERTY) и свои похожие звуки. Пропущенные диакритики (é/e, ü/u, ñ/n) стоят дёшево.
- Для каждого языка есть словарь настоящих слов, похожих на командные: для русского по OpenCorpora, для остальных по частотному словарю wordfreq.
- Формы прошедшего времени и причастия («включил», «opened», «öffnete», «ouvert», «abrió») считаются рассказом о действии и никогда не становятся командой.

Сквозной бенчмарк через настоящего агента (около 3000 опечаток на язык):

|---|---|---|---|
| ru | 76% | 90% | 4,4% → 4,2% |
| en | 78% | 83% | 5,4% → 4,4% |
| de | 78% | 83% | 7,2% → 5,3% |
| fr | 79% | 87% | 7,1% → 5,9% |
| es | 80% | 84% | 6,0% → 5,3% |
| it | 79% | 85% | 6,9% → 5,7% |
| pt | 82% | 84% | 5,1% → 4,9% |

Ни одна опечатка, которую понимала версия 164, не сломалась. Все 1813 разговорных фраз семи языков обрабатываются так же, как в 164.

## Голос: неверно услышанные слова (NEO 166)

Если Whisper записал слово так, как оно прозвучало («превет», «пачему», «bonjoir», «tomorow»), NEO исправляет его («привет», «почему», «bonjour», «tomorrow») и так и пишет в чате. Исправленный текст получает и ассистент. Это работает для обычных фраз, команд и диктовки текста заметок и сообщений.

Слово исправляется, только если выполнены все условия:

- его нет среди известных слов языка;
- рядом есть частое слово или командное слово в пределах маленькой правки (похожий звук, двойная или пропущенная буква, переставленные буквы);
- этот вариант явно лучше остальных.

Никогда не трогаются:

- имена с большой буквы внутри фразы («Скриптонит», «Brakk»);
- слова другого алфавита (Discord в русской речи);
- слова с апострофом и дефисом;
- числа;
- варианты, которые дали бы опасный глагол.

Отключить можно в **Настройки → Голос → «Исправлять неверно услышанные слова»**.

Бенчмарк `python tools/benchmark_spelling166.py`: правильные фразы с одной «услышанной» ошибкой.

| язык | исправлено | исправлено не в то слово | испорчено правильных фраз |
|---|---|---|---|
| ru | 75% | 3,2% | 1 из 1558 |
| en | 78% | 2,3% | 0 из 1501 |
| de | 70% | 2,9% | 1 из 1454 |
| fr | 71% | 2,6% | 0 из 1441 |
| es | 79% | 1,9% | 0 из 1432 |
| it | 72% | 2,9% | 0 из 1432 |
| pt | 78% | 2,2% | 1 из 1442 |

Данные для голоса хранятся в `config/spelling165_<язык>.json`, по одному файлу на язык. В память загружается только текущий язык: 2–4 МБ, в фоновом потоке через 6 секунд после запуска. Интерфейс и анимации его не ждут: пока данные не готовы, фраза просто не исправляется. Файлы собираются командой `python tools/build_spelling165.py`.

## Ресурсы

- Индекс командных слов и словарь настоящих слов хранятся как отсортированные массивы чисел (около 90 КБ и 80–170 КБ на текущий язык). Вместе с кэшами это около 1 МБ; данные для голоса добавляют 2–4 МБ.
- Словарь загружается один раз, примерно за 2 мс.
- Правильно написанная команда проходит слой за десятки микросекунд.
- Более тяжёлый «последний шанс» запускается только тогда, когда без него NEO ответил бы «Не совсем понял».

## Что проверить вручную

| Ввод | Ожидание |
|---|---|
| `jnrhjq gfgre pfuheprb` | открывает папку «Загрузки» |
| `ghbdtn` | отвечает на приветствие |
| `откройпапку загрузки` | открывает папку «Загрузки» |
| `вклюи следущий трек` | следующий трек |
| `cgfcb,j`, `rfr ltkf` | «спасибо», «как дела» |
| `какая пагода` | погода |
| `поставь ан паузу` | то же, что «поставь на паузу» |
| `я включил музыку вчера` | ничего не запускает |
| `удлаи файл C:\x.txt` | ничего не удаляет |

Отключить функцию можно в `settings.json`: `"routing": {"fuzzy_command_repair": false}`.

## Автоматические проверки

Из папки `_internal`, установленным Python приложения:

```text
python -m pytest tests/test_neo165_typos.py
python tools/benchmark_typos165.py --lang ru
python tools/benchmark_spelling166.py
```

Бенчмарк прогоняет около 3000 синтетических опечаток через настоящего агента. Действия при этом заблокированы. Он печатает долю понятых команд и долю случаев, когда опечатка привела к другому инструменту.

Результат на сборке 165 по сравнению со 164:

| | было | стало |
|---|---|---|
| всего | 76% | 90% |
| неправильная раскладка | 0% | 98% |

При этом ни одна ранее понятая опечатка не сломалась.

## Словари

`config/typo_lexicon165.json` (все языки) и `config/spelling165_<язык>.json` собирает разработчик:

```text
pip install pymorphy3 pymorphy3-dicts-ru wordfreq
python tools/build_typo_lexicon165.py
python tools/build_spelling165.py
```

Сборка занимает около 20 минут. Приложению эти пакеты не нужны: оно читает готовые файлы. Источники данных: словарь OpenCorpora (CC BY-SA) и wordfreq (CC BY-SA 4.0).
