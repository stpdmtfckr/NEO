NEO — PROJECT STATUS & DOCUMENTATION
====================================

NEO is currently under active development.

The assistant is being continuously improved and expanded. New features and capabilities will be added over time, existing functionality will be refined, and bugs will be identified and fixed as development progresses. Performance, stability, usability, and the overall assistant experience will also continue to evolve.

Please note that some features may change, and occasional issues may occur while the project is in development. Feedback and bug reports are welcome and help make NEO better.

COMING SOON: MULTILINGUAL USER GUIDEBOOKS
-----------------------------------------

A dedicated folder containing comprehensive user guidebooks will be added to this repository in the future. The documentation will be available in every language supported by NEO.

These guidebooks will include:
- Step-by-step instructions for installing, setting up, and using the assistant.
- Clear explanations of what each setting does and how it affects NEO's behavior.
- An overview of the assistant's features, capabilities, and supported commands.
- Practical examples, usage tips, and recommended configurations.
- Troubleshooting guidance, frequently asked questions, and other useful information.

The goal is to make NEO easy to understand, configure, and use, regardless of the user's experience level or preferred supported language.

Thank you for your interest in NEO and for following its development!
